2

Prepara el Worker

Ya redacté el código fuente. Antes de desplegarlo, revisaremos los términos aplicables y probaremos la autenticación y la conexión. No publiques un proxy abierto.

Ver código preparado en GitHub ↗

Nombre propuesto para el servicio: node-miner-bridge. Por seguridad, el código no lleva credenciales incrustadas.

3

La clave de conexión se configura en privado

El Worker requiere un secreto llamado BRIDGE_TOKEN. Debe generarse y añadirse como Secret dentro de Cloudflare, no como variable pública. No envíes aquí ni ese valor ni la URL completa que lo contenga.

Más adelante podremos utilizar la URL pública del Worker, sin incluir el secreto, para verificar el estado del servicio.

4

Probar conexión y luego minería

Después de tener un Worker seguro y autorizado, comprobaremos el puente. Solo entonces integraremos los trabajos Stratum en NODE MINER. Una conexión correcta no garantiza shares aceptadas ni pagos de Monero.
