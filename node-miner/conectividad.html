Comprobar un puente autorizado

Cuando encontremos un servicio compatible o despliegues un puente propio en un proveedor que permita este uso, pega aquí su URL pública wss:// para verificar la conexión inicial.

No escribas tokens, claves, direcciones de wallet ni contraseñas en esta URL. No aceptamos consultas (?), fragmentos (#) ni usuario:contraseña@.

En espera. No se ha abierto ninguna conexión.

La prueba dura como máximo 8 segundos y no envía mensajes al servidor. El navegador puede transmitir la información normal de una conexión, incluido el origen de esta página y la dirección IP. Safari detendrá la prueba al cambiar de pestaña.

Requisitos para conectar minería real

  • El propietario del servicio debe autorizar explícitamente este uso y el puente debe utilizar WSS cifrado.
  • El puente debe soportar Stratum de Monero / RandomX, no solo aceptar conexiones WebSocket.
  • La autenticación, el pool y sus mínimos de pago deben estar documentados. Ninguna clave privada de Monero es necesaria.
  • Debemos implementar y comprobar la recepción de trabajos, el cálculo de nonces RandomX y la confirmación de shares aceptadas.
  • Las recompensas a 4.67 H/s probablemente serían diminutas; una conexión satisfactoria no garantiza rentabilidad.
