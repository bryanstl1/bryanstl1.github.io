1
GRATIS

Crear tu wallet Monero

Desde tu iPhone puedes instalar Monero.com by Cake Wallet, una wallet no custodiada listada entre las opciones móviles por el proyecto Monero. Es gratuita.

Abrir wallet en App Store ↗
  • Crea un monedero Monero y guarda la frase de recuperación fuera del chat y fuera de NODE MINER.
  • En «Receive / Recibir» → «Accounts and subaddresses» → «Addresses», busca la dirección principal de la cuenta 0, que comienza con 4. La app puede mostrar una subdirección que empieza con 8 por defecto. Para este primer ensayo usaremos la principal.
  • No compartas jamás tu frase semilla, clave privada ni claves de visualización aquí.
Validación local y superficial; no verifica checksum, propiedad de la dirección ni saldo. La dirección permanece solo en esta página. No se envía ni se guarda.

PENDIENTE

Puente seguro WebSocket–Stratum

Safari no puede abrir sockets TCP Stratum directamente. Estamos evaluando un puente ligero en Cloudflare Workers: acepta WebSockets y tiene una API para conexiones TCP salientes. El plan gratuito podría bastar para una prueba de conectividad, pero no confirmamos todavía autorización del caso de uso ni compatibilidad con un pool.
