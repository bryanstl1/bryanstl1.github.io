1
GRATIS

Crear tu wallet Monero

Desde tu iPhone puedes instalar Monero.com by Cake Wallet, una wallet no custodiada listada entre las opciones móviles por el proyecto Monero. Es gratuita.

Abrir wallet en App Store ↗
  • Crea un monedero Monero y guarda la frase de recuperación fuera del chat y fuera de NODE MINER.
  • En «Recibir», copia únicamente la dirección pública principal para cobrar XMR.
  • No compartas jamás tu frase semilla, clave privada ni claves de visualización aquí.
Validación local y superficial; no verifica checksum, propiedad de la dirección ni saldo. No transmitimos ni guardamos este campo.

Los pools reparten pagos según las reglas propias de cada uno. Antes de elegir debemos comprobar que permitan conexión RandomX directa, dificultades adecuadas a un iPhone y mínimos de pago alcanzables.

La documentación oficial de Monero recomienda revisar comisiones, mínimos de retiro y descentralización antes de seleccionar un pool.

PENDIENTE

Puente seguro WebSocket–Stratum

Safari no puede abrir sockets TCP Stratum directamente. Estamos evaluando un puente ligero en Cloudflare Workers: acepta WebSockets y tiene una API para conexiones TCP salientes. El plan gratuito podría bastar para una prueba de conectividad, pero no confirmamos todavía autorización del caso de uso ni compatibilidad con un pool.

PRÓXIMA PRUEBA

Validar un trabajo real

Tras conectar un pool, comprobaremos que el iPhone reciba un trabajo con seed_hash, procese nonces con RandomX y envíe una share válida. Solo una share aceptada por el pool confirmará conectividad minera auténtica; no equivale automáticamente a un pago.
